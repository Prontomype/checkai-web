# CheckAI Web V1

Primera versión de landing page estática para CheckAI.

## Archivos
- `index.html`: página principal
- `styles.css`: estilos responsive
- `script.js`: menú, animaciones y demo del asistente IA
- `assets/`: imágenes extraídas del pitch deck proporcionado por el equipo

## Publicación gratuita en GitHub Pages
1. Crear un repositorio, por ejemplo `checkai`.
2. Subir todos los archivos manteniendo la misma estructura.
3. Ir a **Settings → Pages**.
4. En **Build and deployment**, seleccionar **Deploy from a branch**.
5. Elegir `main` y `/ (root)`.
6. Guardar. GitHub publicará la página en una URL tipo `https://usuario.github.io/checkai/`.
